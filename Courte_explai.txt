Consignes données par IA

Sur Zindi, vous avez une seule mission (ce challenge). Vous allez travailler sur le même jeu de données et le même objectif (prédire les rendements) pendant toute la durée de la compétition.
Le processus typique :

    Première soumission : Vous préparez un modèle basique, vous créez un fichier submission.csv, vous le soumettez. Vous obtenez un score sur le leaderboard public.

    Analyse du score : Vous regardez votre score, vous le comparez aux autres participants.

    Amélioration du modèle :

        Vous analysez où votre modèle a des faiblesses

        Vous testez de nouvelles techniques (feature engineering, autres modèles, tuning)

        Vous entraînez un nouveau modèle avec ces améliorations

    Deuxième soumission : Vous générez un nouveau fichier CSV avec les prédictions de votre modèle amélioré et vous le soumettez.

    Répétez : Vous continuez ce cycle d'amélioration jusqu'à avoir un modèle satisfaisant ou avoir utilisé vos 60 soumissions.

Pourquoi 20 soumissions par jour ?

C'est pour vous encourager à :

    Réfléchir avant de soumettre

    Valider localement vos modèles avant de les envoyer

    Ne pas spammer avec des variations aléatoires

Stratégie recommandée

    Validez localement avec une validation croisée temporelle (train sur 2016-2021, val sur 2022-2023)

    Soumettez uniquement quand vous êtes satisfait de votre score en validation

    Gardez des soumissions pour les derniers jours (vous pouvez tomber sur une bonne idée)
